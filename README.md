# Roman Character Recognition System

A deep learning-based Roman character recognition system built using a custom PyTorch CNN. The project classifies Roman characters from images using preprocessing, model training, evaluation, serialization, and a simple web-based inference interface.

## Features

- Image preprocessing pipeline
- Custom CNN architecture in PyTorch
- Multi-class Roman character classification
- Model training and evaluation
- Saved model for inference
- Web-based interface for predictions

## Tech Stack

- Python
- PyTorch
- NumPy
- OpenCV / PIL
- HTML/CSS
- Flask or FastAPI

## Use Case

This project demonstrates how computer vision can be used for optical character recognition tasks, handwritten/text classification, and educational AI applications.
